# Landing page Odin Project

Projeto de **landing page** desenvolvido como parte da lição [Landing Page](https://www.theodinproject.com/lessons/foundations-landing-page) do The Odin Project. Este repositório reúne uma página estática construída com HTML e CSS, com foco em estruturação de layout, organização de seções e estilização com Flexbox.

## Sobre o projeto

A proposta deste exercício é recriar uma landing page a partir de um layout de referência, praticando fundamentos importantes do front-end. Nesta implementação, a página foi organizada em blocos principais como header, área principal, seção de destaque, chamada para ação e footer, seguindo a ideia central do desafio do Odin Project.

O HTML está dividido em seções principais para separar melhor o conteúdo e facilitar manutenção. Entre os blocos presentes no projeto estão a área de cabeçalho, uma seção de apresentação, um bloco com citação ou frase de destaque, uma call to action com botão de contato e um rodapé com crédito autoral.

O CSS trabalha cores, alinhamento e espaçamento para construir a identidade visual da página. A estilização utiliza containers com `display: flex`, além de classes específicas para textos, botões, rodapé e blocos de conteúdo.

## Tecnologias

- HTML5
- CSS3
- Flexbox

## Aprendizados praticados

Este projeto ajuda a desenvolver noções essenciais de front-end, especialmente composição visual e organização semântica da interface. Entre os pontos praticados estão estruturação em seções, uso de classes reutilizáveis, alinhamento com Flexbox, personalização de botões e controle de tipografia, cores e espaçamento.

## Arquivos do projeto

| Arquivo | Função |

## Melhorias futuras

Algumas evoluções naturais para este projeto seriam ajustar nomes de arquivos para algo mais convencional, adicionar conteúdo real no lugar de textos temporários e melhorar a responsividade para telas menores. Também faria sentido incluir uma captura de tela do resultado final e publicar a versão hospedada no GitHub Pages para deixar o repositório mais completo.
